# Women's Safety Web App

## About
Full-stack web application providing real-time safety support for women 
in unsafe situations. Core features include an AI-powered safety chat, 
live safe-location detection via Google Maps, an emergency contact 
button, and a one-tap safety protocol for high-stress situations.

Built as part of the "Foundation and Applications of Generative AI" 
course at TUM Campus Heilbronn (2025). Reached go-live testing phase 
with real user feedback integration.

## My Role
- Co-led initial environment setup and application architecture
- Contributed to full-stack development (Flask backend + JS frontend)
- Integrated OpenAI GPT-3.5-turbo with custom system prompts tuned 
  for safety-specific response behaviour (tone, token limits, 
  temperature settings)
- Integrated Google Maps Places API for real-time safe-location 
  detection and navigation
- Conducted user case study to validate core features against 
  real user needs; findings fed directly into prototype iteration
